# Revue tech lead — PR #139 « feat(web): nouvelle application unique, connexion, accueil et design system v1 » — 3 octobre 2026

## Verdict

**Bloquant** (avant corrections). Le socle est solide : PKCE, retour de connexion sûr, aucun HTML brut, tests axe-core et de contraste. Mais le parcours « moins de 15 ans » ne mène jamais à sa page, le realm a été retouché à la main et n'est plus aligné sur son générateur (déconnexion), et l'en-tête déborde à 320 px.

Vérifié par commande sur `639d662` : 92 tests web, `typecheck`, `pnpm lint`, `build` (un seul fichier de 669 kB) ; `pnpm audit --prod` sans résultat ; dépendances toutes publiées avant le 26 septembre (`minimumReleaseAge`) ; mesure à 320 px dans le navigateur ; lecture du code de `react-oidc-context` et `oidc-client-ts` installés.

## Points positifs

- Flux OIDC propre : PKCE S256, client public sans mot de passe direct, `credentials: 'omit'`, jeton envoyé uniquement vers l'API (même origine), chemin de retour filtré et testé.
- Markdown rendu en éléments React, liens limités à `https://`, `/` et `#` ; aucun `dangerouslySetInnerHTML` ; thème appliqué par un fichier séparé (compatible CSP stricte).
- Bonne base d'accessibilité : lien d'évitement, focus sur `main`, titre d'onglet par page, `<output>`, champs reliés à leur aide et à leur erreur, page courante signalée sans la seule couleur, mouvement réduit, cibles de 44 px, bordure des champs assombrie et documentée.
- Erreurs RFC 9457 bien exploitées (`fieldError('handle')`, focus sur le champ).
- Nettoyage complet des ports 5000-5002 ; dépendances récentes sans vulnérabilité connue.
