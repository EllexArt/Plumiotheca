# Revue tech lead : PR #157 « procédure des rôles d'équipe, TOTP d'abord » (8 octobre 2026)

Verdict initial : **changements demandés**. Le script faisait ce qu'il annonçait, mais des essais sur le Keycloak de développement (comptes et groupe jetables, supprimés ensuite) ont montré que le but de #125 n'était pas atteint.

## Faille trouvée (antérieure à la PR)

« Mot de passe oublié » restait ouvert aux rôles d'équipe. Avec `kc_action=CONFIGURE_TOTP` dans l'URL d'autorisation, le lien reçu par e-mail ouvrait une session où un **second code TOTP** pouvait être enregistré : la boîte mail suffisait pour obtenir une session de modération avec `amr = ["pwd","otp"]`, acceptée par l'API. `check-realm.mjs` ne testait pas ce cas, et la documentation affirmait le contraire.
